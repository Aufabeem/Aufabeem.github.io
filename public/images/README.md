# Images Folder

Letakkan semua gambar Anda di folder ini:

## Struktur yang disarankan:
```
public/images/
├── profile.jpg          # Foto profil utama
├── about-working.jpg    # Gambar untuk section About
├── projects/
│   ├── project-1.jpg    # Screenshot project 1
│   ├── project-2.jpg    # Screenshot project 2
│   ├── project-3.jpg    # Screenshot project 3
│   ├── project-4.jpg    # Screenshot project 4
│   ├── project-5.jpg    # Screenshot project 5
│   └── project-6.jpg    # Screenshot project 6
└── icons/
    └── favicon.ico      # Icon website (opsional)
```

## Format yang disarankan:
- **Foto profil**: 400x400px (square/persegi)
- **Gambar About**: 500x600px (portrait)
- **Screenshot Projects**: 600x400px (landscape)
- **Format**: JPG atau PNG
- **Ukuran file**: Maksimal 500KB per gambar untuk performa optimal

## Cara menggunakan:
1. Upload gambar ke folder yang sesuai
2. Pastikan nama file sesuai dengan yang ada di kode
3. Atau edit nama file di komponen React sesuai nama gambar Anda
